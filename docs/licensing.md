# Licensing and redistribution notes (2026-11-14)

Not legal advice. This records what was checked, so the open questions in the backlog are concrete.

## What our image is made of
| Part | Licence (as found) | Can the image/files be redistributed? |
|---|---|---|
| AOSP / LineageOS 21 source and the apps we kept (Settings, SystemUI, Messaging, Dialer, Contacts, FMRadio, ...) | Apache 2.0 (headers checked on FMRadio; AOSP is Apache 2.0 except some GPL/LGPL libraries) | Yes, with notices; no trademarks (we do not call it Android/Lineage branded product). |
| TrebleDroid device tree (`device/phh/treble`, `treble_app` source) and `patches-for-developers.zip` | No LICENSE file in the zip or the device tree; the files carry no explicit licence header (rw-system.sh has none); the project is open source on GitHub. **Licence unread/unclear.** | Our own patches against it (build/patches/*.patch) are small diffs; publishing diffs is normal practice, but ask the TrebleDroid maintainers or check their repository page for the licence before publishing an image or the tree. |
| `vendor/hardware_overlay` (TrebleDroid) incl. the prebuilt `TrebleApp` APK | Same as above; the APK is a prebuilt binary | Same question. |
| TT9 (io.github.sspanak.tt9) | Apache 2.0 (upstream project); APK taken unchanged from its GitHub release | Yes, keep its signature and notices. |
| Phone Guard (this repo) | Apache 2.0 (`LICENSE`) | Yes. |
| **Qin/MediaTek proprietary files**: the IMS apps and jars (ImsService, MtkGbaService, MtkTelephonyAssist, MtkCapCtrl, mediatek-*.jar, mediatek-res), the stock MtkCarrierConfig, MediaTek native libs in `build/ims/proprietary`, any stock FM fallback files, the ported stock SELinux labels | Proprietary, copyright Qin/Duoqin and MediaTek. Not licensed to us for redistribution. Taken from the owner's own phone for use on that phone. | **No.** Keep them out of git, GitHub and any public image. A public build must leave them out (phone then has no VoLTE) or the user must extract them from their own device. |
| Qin vendor partitions, kernel, bootloader (we do not rebuild or ship them; the image is system only) | Proprietary; the Linux kernel is GPLv2 | We do not distribute the kernel; if we ever ship a boot image, the GPL source offer applies. Kernel source request to Qin is still on the backlog. |

## Consequences
- The kits in `/artifacts` and the NAS backups are private working copies. Do not publish a system.img: it contains the proprietary MediaTek files.
- Anything pushed to GitHub is source we may publish (build scripts, patches, our overlays/sepolicy, docs). The repo already keeps proprietary inputs out (`.gitignore`, `/archive`).
- Signing keys (docs/signing-keys.md) are secrets, never in git.
- Before releasing anything to other people: (1) settle the TrebleDroid licence with its maintainers, (2) decide how MediaTek files get onto a user's phone (extract on-device, or a separate private download), (3) check notice requirements for the Apache components (NOTICE files in the image: `/system/etc/NOTICE.xml.gz` is generated by the build).
