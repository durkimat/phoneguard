# Phone Guard image ims38 (release notes)

Published as the GitHub release [image-20261114](https://github.com/durkimat/phoneguard/releases/tag/image-20261114).

**What this is:** a system image (`system.img`, Android 14 from LineageOS 21 with TrebleDroid patches, plus our patches) for the **Qin J36** keypad phone (MT6761). Only the `system` partition is written; the vendor side stays the phone's own. It has Phone Guard built in as a privileged system app (version 0.3.14 inside; later versions update from GitHub releases), the keypad launcher, VoLTE/IMS support and TT9 keypad input.

**Install:** follow [docs/getting-started.md](https://github.com/durkimat/phoneguard/blob/main/docs/getting-started.md); the easy way is the installer (`node pg-install.mjs all --download` in `installer/`), which downloads these two files, checks them, takes a basic backup of the phone's details and flashes. A deeper, read-only backup of the phone's IMEI and radio data is recommended first (see [docs/recovery-guide.md](https://github.com/durkimat/phoneguard/blob/main/docs/recovery-guide.md)). The image must be flashed to an **unlocked** J36; this erases the phone.

**Assets** (keep the names; the installer looks for them):
* `system.img.gz`: gzip of the exact image, 1,072,836,757 bytes
* `SHA256SUMS`: sha256 of the uncompressed `system.img` (`eb959c504ec3176fd5fb89a8b15a657995fb9aa22b919b9f0b30d31af0081eeb`, 2,352,816,128 bytes) and of the `.gz`

**Known issues / untested:**
* FM radio: the Lineage FM app is in the image but not proven on this phone (needs wired headphones as the aerial; not yet tested).
* Wi-Fi calling: untested. Bluetooth: A2DP music works; headset call audio (HFP) not tested.
* Screen wake cycle (the screen lights, dims and sleeps repeatedly) was seen while plugged into a PC over USB; not yet diagnosed.
* Some checks of this build are still pending (PIN set while the screen is off, clearing a PIN): see the test list in BACKLOG.md.
* Built with our own signing keys; it is a development build (`userdebug`).
