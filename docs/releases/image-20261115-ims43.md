# Phone Guard image ims43 (release notes)

Published as the GitHub release [image-20261115](https://github.com/durkimat/phoneguard/releases/tag/image-20261115).

**What this is:** a system image (`system.img`, Android 14 from LineageOS 21 with TrebleDroid patches, plus our patches) for the **Qin J36** keypad phone (MT6761). Only the `system` partition is written; the vendor side stays the phone's own. It has Phone Guard built in as a privileged system app (version 0.4.17 inside; later versions update from GitHub releases), the keypad launcher, VoLTE/IMS support and TT9 keypad input.

**Install:** follow [docs/getting-started.md](https://github.com/durkimat/phoneguard/blob/main/docs/getting-started.md); the easy way is the installer (`node pg-install.mjs all --download` in `installer/`), which downloads these two files, checks them, takes a basic backup of the phone's details and flashes. A deeper, read-only backup of the phone's IMEI and radio data is recommended first (see [docs/recovery-guide.md](https://github.com/durkimat/phoneguard/blob/main/docs/recovery-guide.md)). The image must be flashed to an **unlocked** J36; this erases the phone.

**Assets** (keep the names; the installer looks for them):
* `system.img.gz`: gzip of the exact image, 1,072,922,347 bytes
* `SHA256SUMS`: sha256 of the uncompressed `system.img` (`82e77d151bb0bce6d0e54c62b675fda94c9b6f5aa8812ee7fab9507bb9446e07`, 2,353,000,448 bytes) and of the `.gz`

**Known issues / untested:**
* FM radio: the Lineage FM app is in the image but not proven on this phone (needs wired headphones as the aerial; not yet tested).
* Wi-Fi calling: untested. Bluetooth: A2DP music works; headset call audio (HFP) not tested.
* Screen wake cycle (the screen lights, dims and sleeps repeatedly) was seen while plugged into a PC over USB; not yet diagnosed.
* Some checks of this build are still pending (PIN set while the screen is off, clearing a PIN): see the test list in BACKLOG.md.
* Built with our own signing keys; it is a development build (`userdebug`).

**Licensing notice (please read):** this image contains **27 Qin/MediaTek proprietary files (15.3 MB)** (IMS apps, framework jars and radio libraries taken from the phone's own firmware) and **TrebleDroid parts whose licences are still being clarified** (a prebuilt app, overlays and scripts). They are included here **for owners of the J36, for personal use**, under the project owner's decision of 2026-11-14 while the licences are clarified. The release **may be withdrawn at any time**; copies already downloaded cannot be recalled. Details: [docs/licensing.md](https://github.com/durkimat/phoneguard/blob/main/docs/licensing.md) and [docs/image-redistribution.md](https://github.com/durkimat/phoneguard/blob/main/docs/image-redistribution.md). ## What is new since the 2026-11-14 image
- Phone Guard 0.4.17 inside (the image before shipped 0.3.14): Open and Family editions chosen on the first-run wizard (Wi-Fi, time zone and language, phone type), the screen-lock PIN, the data and weather home screen, the restructured menu, and keypad access to the home screen's symbols.
- A fresh install no longer needs a round of app updates before it matches the current companion.
- Image sha256 and file: see the release assets (`system.img.gz`, `SHA256SUMS`). The Qin and TrebleDroid licensing notice is unchanged.
